# まいにちTOEIC 仕様書

## 概要
英語が苦手な人が「毎日少しずつ」TOEIC対策を続けられる学習教材アプリ。Part 1〜7 のパートごとに解説レッスンと練習問題を用意し、試験日までのカウントダウンと毎日の学習習慣（連続日数＝ストリーク）で継続をサポートする。ブラウザだけで動き、データは端末内（localStorage）に保存される。

## ターゲットユーザー
- 英語が苦手な初心者〜TOEIC 400点を目指す人
- まずは作者本人が毎日使う（自分専用）
- 一歩ずつ・基礎から学びたい人

## コンセプト（大事にすること）
1. **毎日続ける** — ホームに「今日のタスク」と連続日数を大きく表示。1日5〜10分でも達成できる量に。
2. **一歩ずつ** — 各パートを「解説 → 例題 → 練習」の順に。専門用語は最小限、日本語の解説を丁寧に。
3. **試験日管理** — 残り日数のカウントダウンと全体の進捗を見える化。

## 技術スタック
| 項目 | 内容 |
|------|------|
| 言語 | HTML / JavaScript（バニラJS） |
| スタイル | Tailwind CSS（CDN） |
| データ保存 | ブラウザの localStorage（端末内） |
| 音声 | Web Speech API（SpeechSynthesis）でブラウザ読み上げ。音声ファイル不要 |
| ホスティング | 不要（ローカルでファイルを開くだけ。将来 GitHub Pages 等も可） |
| 認証 | なし（自分専用） |

## 各パートページの共通構成
1. **解説レッスン** — そのパートの出題形式・解き方のコツを日本語でやさしく解説。
2. **例題（1問）** — 解説を見ながら一緒に解く例。
3. **練習問題（数問）** — 自分で解く → その場で正誤判定 → 解説表示。
4. **完了ボタン** — 「今日の学習」に達成として記録（ストリーク・進捗に反映）。

リスニング系（Part 1〜4）は問題文・選択肢を Web Speech API で読み上げ、再生／もう一度ボタンを設置する。

## 主要機能
1. **試験日カウントダウン** — 設定した試験日までの残り日数を表示。未設定なら設定を促す。
2. **毎日の学習習慣（ストリーク）** — その日に1つでもパートを完了すると連続日数が加算。カレンダー風の達成表示。
3. **今日のタスク** — その日に取り組むパートを提案（曜日ごとにローテーション等）。
4. **進捗の見える化** — 各パートの完了状況・全体の進捗バー。
5. **パート別学習** — 解説＋練習問題で1パートずつ対策。
6. **単語帳** — 頻出単語をフラッシュカードで暗記。
7. **リスニング読み上げ** — 音声ファイルなしでリスニング練習。

## データモデル（localStorage）
キー `mainichi-toeic` に以下を JSON で保存：
```
{
  "examDate": "2026-09-13",          // 試験日（未設定なら null）
  "targetScore": 400,                 // 目標スコア
  "streak": 7,                        // 現在の連続日数
  "lastStudyDate": "2026-06-04",      // 最後に学習した日
  "studyDates": ["2026-06-01", ...],  // 学習した日付の一覧（カレンダー表示用）
  "partProgress": {                   // パートごとの進捗
    "part1": { "completed": 3, "total": 5 },
    ...
  },
  "vocabKnown": ["abundant", ...]     // 覚えた単語
}
```

## コンテンツ方針（初心者〜400点）
- 練習問題は各パート3〜5問のサンプルを同梱（まずは少量で「続けられる」ことを優先）。
- 解説は中学英語レベルの言葉で。文法用語には必ず補足をつける。
- 単語帳は TOEIC 頻出の基礎単語からスタート。
